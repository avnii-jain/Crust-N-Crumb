# 🍰 CRUST N CRUMB
Crust N Crumb is a **full-stack e-coerce web application** for browsing and purchasing bakery products.

**Project Status: Work in Progress**

The project is currently under active deployment. New features, improvements, and fixes will be added regularly.

## 🛠️ Tech Stack

### Frontend
- React.js
- JavaScript
- HTML
- CSS
- Bootstrap

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose

### Admin Panel
- React.js
- JavaScript

### Other Technologies
- Git & GitHub
- Cloudinary
- REST APIs
